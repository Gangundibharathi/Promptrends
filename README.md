## 📌 Project Overview

**PrompTrends.in** is a web platform built to help users discover, explore, and share trending AI prompts across multiple categories and use cases.  
As AI tools like ChatGPT, Midjourney, and other generative models grow rapidly, high-quality prompts play a crucial role in achieving better results. PrompTrends bridges this gap by providing a centralized hub for prompt discovery and community contribution.

The platform focuses on **simplicity, usability, and scalability**, allowing users to quickly find prompts that are currently popular or relevant to their needs.

---

## 🎯 Key Objectives

- Create a centralized repository for trending and curated AI prompts  
- Allow users to explore prompts by category and popularity  
- Enable community participation through prompt submissions  
- Build a scalable backend to manage prompt data efficiently  
- Provide a clean and responsive user experience  

---

## ✨ Features

### 👤 User Features
- Browse trending and curated AI prompts  
- Explore prompts by categories  
- View detailed prompt descriptions  
- Submit new prompts to the platform  
- User authentication (Signup & Login)  
- Simple and intuitive UI for smooth navigation  

### 🛠 Admin / Platform Features
- Manage prompts and categories  
- Moderate user-submitted content  
- Maintain structured prompt data in the database

## 🧱 Tech Stack

### Backend
- **PHP**
- REST-style architecture
- Handles business logic, authentication, and database operations  

### Frontend
- **HTML**
- **CSS**
- **JavaScript**
- Responsive and user-friendly UI  

### Database
- **MySQL**
- Relational data management for users, prompts, and categories  

### Tools & Environment
- Local server (XAMPP / LAMP / similar)
- Version Control: **Git & GitHub**

---

## 🗂 Database Design (High Level)

- **Users Table**
  - User ID
  - Name
  - Email
  - Password (hashed)
  - Created At  

- **Prompts Table**
  - Prompt ID
  - Title
  - Description
  - Category
  - Created By (User/Admin)
  - Created At  


- **Categories Table**
  - Category ID
  - Category Name  

---

## 🔐 Authentication & Security

- Secure user authentication system  
- Password hashing to protect user credentials  
- Server-side validation for inputs  
- Role-based access (Admin vs User)  

---

## 📈 Scalability & Design Considerations

- Modular backend structure for easy feature expansion  
- Database normalized for performance and maintainability  
- Designed to support future features like:
  - Prompt likes & bookmarks
  - User profiles
  - Analytics & trending algorithms
  - API support for third-party integrations
